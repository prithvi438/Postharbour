# Emoji data

Generated from https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt. Contains 3944 fully-qualified Unicode 17.0 emoji sequences, including skin-tone variants. See UNICODE-LICENSE.txt. Glyphs use device fonts; no WhatsApp artwork. No runtime third-party requests.

Regenerate with `python3 scripts/update_emoji_data.py`; then run `npm run format`
in `frontend/`. This downloads only official Unicode data and its license.
